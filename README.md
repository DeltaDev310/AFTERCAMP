# AFTERCAMP

> **A short psychological horror game about a girl who may have never existed.**

You return to an abandoned summer camp years after a girl disappeared.

You remember her.

Nobody else does.

The photographs say something different.

And something in the woods doesn't want you to leave.

**AFTERCAMP** is a short, atmospheric 2D horror experience focused on exploration, mystery, and unanswered questions.

---

## Features

* Top-down 2D exploration
* Atmospheric camp environment
* Photo-based investigation system
* Randomized 5-digit escape code
* Persistent clues and progression
* Enemy AI with:

  * Patrol
  * Chase
  * Return behavior
* Jumpscare system
* Multiple scenes and story sequences
* Environmental storytelling

---

## The Unraveler

Something is wandering around the camp.

It doesn't simply hunt you.

It **unravels you**.

The Unraveler can patrol the camp, detect the player, give chase, and return to its territory when you escape.

---

## Find the Photos

Five photographs are hidden throughout the camp.

Each one contains part of the code needed to escape.

But the photographs raise a bigger question:

**Why do they prove something that nobody remembers?**
